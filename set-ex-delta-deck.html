บทสรุปผู้บริหาร

  • ประเด็นเชิงโครงสร้างตลาด: SET Composite ไม่มีการจำกัดน้ำหนักหุ้นรายตัว (no single-stock weight cap) ขณะที่ SET50/SET100 และดัชนี Free-Float variants ใช้วิธี capped-weight
  • น้ำหนัก DELTA ณ 8 ก.ค. 2026 = 18.66% (มูลค่าตลาด 3.72 ล้านล้านบาท จากทั้งตลาด 19.92 ล้านล้านบาท) และเคยขึ้นสูงสุด 22.68% เมื่อ 9 มิ.ย. 2026
  • ข้อค้นพบสำคัญ: รอบ 3 ปี SET Composite +5.3% แต่หากตัด DELTA ออก ตลาดติดลบ 8.0% — ผลตอบแทนบวกของดัชนีมาจาก DELTA เกือบทั้งหมด
  • ข้อเสนอ: ไม่ใช่การถอด DELTA ออกจาก SET Composite แต่เป็นการจัดทำดัชนีเสริม SET ex-DELTA เพื่อเพิ่มความโปร่งใส โดยไม่กระทบ benchmark เดิม

ประเด็นหลัก: ดัชนีสะท้อน DELTA มากกว่าตลาดโดยรวม

  • เมื่อ DELTA มีน้ำหนักเข้าใกล้ ~19% ของมูลค่าตลาดรวม ดัชนีจึงสะท้อนการเคลื่อนไหวของ DELTA มากขึ้น แทนภาพรวมตลาดหุ้นไทย
  • ควรวางกรอบเป็นข้อเสนอด้านความโปร่งใส / ดัชนีเสริม ไม่ใช่การเสนอถอดหุ้นออกโดยตรง

วิธีการคำนวณและการตรวจสอบความถูกต้อง

  • การปรับ Base Market Value (BMV): เมื่อนำหุ้นออกจากดัชนี SET จะปรับ BMV ตามหลัก continuity เพื่อให้ Index after adjustment = Index before adjustment ดังนั้นระดับดัชนีจะไม่เกิด price shock จากการปรับองค์ประกอบเพียงอย่างเดียว
  • สร้างดัชนี SET ex-DELTA ใหม่ด้วยวิธี divisor-continuity chain จากข้อมูลรายวันดิบ
  • ผลการตรวจสอบ (acceptance test): ความคลาดเคลื่อนสูงสุด = 0.0 bps ตลอด 727 วันทำการ — สร้าง SET Composite ที่ตรงกับดัชนีที่เผยแพร่จริงทุกวัน จึงเชื่อถือเส้น ex-DELTA ได้

ผลต่อกองทุนและผลิตภัณฑ์อ้างอิงดัชนี

  • ผลิตภัณฑ์ที่อ้างอิงดัชนี SET อาจต้องปรับพอร์ต (rebalance) ขึ้นอยู่กับ mandate และขนาด AUM ของแต่ละกอง
  • การกระจุกตัวสูงทำให้ความเสี่ยงกระจุกตัวส่งผ่านไปยังพอร์ต passive ที่อ้างอิง SET Composite
  • ข้อเสนอด้านดัชนีเสริมมีเป้าหมายเพิ่มความโปร่งใส โดยไม่รบกวน benchmark, mandate หรือผลิตภัณฑ์เดิม

ข้อเสนอแนะ: ลำดับทางเลือก

ทางเลือกข้อเสนอเหตุผล
A. จัดทำดัชนีเสริม SET ex-DELTA แนะนำแนะนำรบกวนน้อย โปร่งใสสูง เป็นก้าวแรกที่ปฏิบัติได้จริง
B. ใช้ capped weight กับ SET Compositeพิจารณาระยะยาวต้องทำ public hearing และทบทวนวิธีคำนวณในวงกว้าง
C. คงสถานะเดิม + เพิ่มการเปิดเผยข้อมูลทางเลือกขั้นต่ำเพิ่มการมองเห็น แต่ไม่แก้ปัญหาการบิดเบือน benchmark

การถอด DELTA ออกจาก SET Composite ทำได้ยากภายใต้วิธีคำนวณปัจจุบัน เพราะ SET Composite ออกแบบมาเพื่อสะท้อนหุ้นสามัญทั้งตลาดภายใต้เกณฑ์คัดออกที่มีอยู่
