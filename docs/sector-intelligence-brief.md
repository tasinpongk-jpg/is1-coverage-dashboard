4. _Analyst inference_ · NPAT **+54.2%** — The segment conclusion combines audited panel arithmetic with issuer-specific MD&A and is not a single-company causal proof.

#### Causal proof chain

**Livestock price** (↑ recovery driver) → **Feed cost / soybean** (↓ cost tailwind) → **Margin** (5.1% +1.8 ppt YoY) → **NPAT** (+54.2% THB 40.3bn FY2025) → **Valuation** (7.8x YTD +13.6%)
